# かにかかい

かにか、かいか。札を選んで泡を集める、ちょっと奇妙な選別所。

## 遊ぶ

Macでは **`あそぶ.command` をダブルクリック**すると、ローカルのゲームを開きます。起動中はターミナルを開いたままにしてください。終了はターミナルで `Control + C`。

手動で起動する場合（Node.js 22.12以上推奨。開発・確認環境は24.13.0）：

```sh
npm ci
npm run dev
```

ブラウザで **http://127.0.0.1:4288/** を開きます。保存はこのブラウザ・このURL内です。別ブラウザや別ポートとは進行を共有しません。

## 操作

- 扉のカニ・貝を押すと名前が聞けます。「しごとを はじめる」で波とともに選別所へ。3つの合図と高い開始音のあと、30秒が始まります。
- 色のついたお題の絵に合う文字札をクリック。もう一方の絵はシルエット。正解で **＋10泡**、カニが「ぷくっ」。
- 第1の仕事は「かに」を5枚取りきると次の束へ。第2の仕事以降は正解ごとに札がシャッフルされます。各束は正解5枚・もう一方4枚。
- 30秒以内に目標へ。達成後は「材料を うけとる」で先に進めます。残り時間で記録を伸ばすのも自由。
- 間違えるとカニが「やれやれ」。**−5泡（下限0）**。その札だけ短い間選べなくなります。
- 画面上の題名を押すと扉へ戻ります。仕事中なら時間・泡を保って再開できます。
- 「ひとやすみ」または Escape で休憩。別タブに移った場合も休憩します。
- キーボードの 1〜9 でも、左上から順に札を選べます。
- 音は右上で切り替え。声の仕事はお題の聞き直しボタン「文字でみる」が使えます。
- 材料・自己ベスト・料理カードは自動保存。保存できない場合は画面下に表示します。

1ステージ＝5つの短い仕事。ステージ1をクリアすると料理カードを獲得できます。レシピブックでカードを押すと、獲得日・獲得泡・材料と、カニのゆるい作り方が読めます。現在は1料理のサンプルです。PCブラウザが主対象。スマホ幅のレイアウトもありますが、実機検証・アプリ化はこれからです。

## 開発

Phaser 3.90 + TypeScript + Vite。Phaserはカニの表情・泡を描画し、操作する札と日本語UIはDOMで扱います。ルールは描画から独立しています。

```sh
npm test       # 時間・連打・目標・保存データのルールを検証
npm run build # 型検査と静的ビルド
npm run preview # ビルド結果を同じローカルURLで確認（devと同時起動しない）
```

- `src/game/`：ゲームルール、保存、ルールテスト
- `src/view/`：カニの描画、扉と波、指示札、レシピブック
- `src/main.ts`：画面とゲーム状態の接続
- `src/audio.ts`：短い効果音とブラウザの日本語読み上げ
- `public/assets/characters/`：生成したカニ・貝・料理の切り絵素材
- `public/assets/ingredients/`：集める材料5つの切り絵素材
- `assets/concepts/`：承認済みの画面案
- `scripts/playtest*.js`：Playwright CLI用の実操作確認（独立したテスト用ブラウザコンテキスト）
- `output/playwright/`：確認時のスクリーンショット。完成料理の画像を含みます。

企画の決定は `DECISIONS.md`、現在地は `HANDOVER.md` を参照してください。

以前の保存データも引き継ぎます。獲得日・合計泡を記録していなかった料理カードは、その欄を「記録なし」と表示します。

## Web公開の準備

ゲームは `npm run build` で生成する `dist/` だけで配信できます。公開URLはまだありません。

GitHub Pages用の `.github/workflows/pages.yml` を用意しています。リポジトリでPagesのSourceをGitHub Actionsにし、Actionsのリポジトリ変数 `PAGES_ENABLED=true` を設定すると、`main` の更新時にテスト・ビルド・公開を行います。無料プランで公開リポジトリを使う場合、コードや素材、制作文書も一般公開されます。現時点は公開範囲の確認待ちです。

サブパスでの確認例：

```sh
npm run build -- --base=/kani-ka-kai/
npx vite preview --host 127.0.0.1 --port 4289 --strictPort --base=/kani-ka-kai/
```

`http://127.0.0.1:4289/kani-ka-kai/` を開きます。ローカル・公開サイト・別ブラウザの進行はそれぞれ独立です。
